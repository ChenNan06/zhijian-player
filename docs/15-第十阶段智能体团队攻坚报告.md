## 2. 六处真因与初判不同（团队纠错）

1. **视频点不动**：不是「全局过滤器拦截」，而是 **`top/middle/bottom_layer` 只在图片模式设了穿透**。
2. **频谱死水**：不是「滤镜参数错」，而是 **`_src_tried` 一次性开关**导致 loadfile 后永远不再重挂 astats。
3. **标题残留**：`_title_text` 音频分支 **return 后赋值被吞** + `_on_file_loaded` 的 else 把音频也写 px。
4. **菜单多高亮**：**`MenuRow` 只靠 enter/leave**（快速划过漏 leave）+ QMenu 原生 selected 蓝底叠加。
5. **模态键泄漏**：audio_view 的应用级 eventFilter **先于**设置面板安装 ⇒ 方向键仍能 seek ⇒ 改为打开时**最后安装** KeyGuard。
6. **video 三角**：确认是**朝上的等边三角**（H:W 0.8542），非「样式不对」。

## 3. 四个「静默失败」型隐藏 bug（本阶段最有价值的一类）

1. **`setMinimumSize(800,560)` 把 `setGeometry(480×270)` 静默夹成 800×560** ⇒ PiP 小窗根本不会变小（已临时放宽 + 退出逐位还原）。
2. **`QRect` 未 import ⇒ `NameError` 被兜底 `except` 吞掉** ⇒ 表现成「点了还是没反应」，**与用户原 bug 一模一样**、极易误判成「没接线」（已把 traceback 存进 `pip_state()['pip_error']`）。
3. **QSS 8 位 hex 是 AARRGGBB** ⇒ `#FFFFFFA6` 被当成不透明淡黄（实测 255,255,166）。
4. **palette 必须在 QSS/re-polish 之后落**，否则标题栏被刷回 `#F7F8FA` 纯白块。

## 4. 方法论沉淀

- **玻璃态 `widget.grab()` 全透明全 0** ⇒ 必须**真实屏幕抓取**（QA 与 Dev 各自踩过）；
- **掩膜要先排除底板**：video.ico 的底板本身饱和 + 视窗右上还有装饰元素 ⇒ 必须**取最大连通域**（QA 四次失败、Lead 给出配方后 1 分钟复现）；
- **跨媒体切换类**判据必须「先充分播放再切」（QA 第一版只播 2s ⇒ 两臂都 ~1.0、根本测不出 bug）；
- **暂停真源是 `engine.get('pause')`**（`w._playing` 不存在）；**全屏是 borderless 改几何 ⇒ `isFullScreen()` 恒 False**；
- **收口前清场**：本阶段清理 **19 个 `zhj*` 残留实例** + 仓库根垃圾文件 `nul`（Windows 保留设备名，需 `\\?\` 扩展路径删除）。
