### Task-102 · P0 模糊画质 + resize 冻结 + 抽屉手柄统一（用户问题 3/8）

**三个修法**：

1. 降采样 `Qt.FastTransformation → Qt.SmoothTransformation`（双线性），模糊半径提到等效 **36~48px**；
2. 模糊纹理更新用**新旧 0.25 : 0.75 Alpha 混合**（temporal blend），消除 20Hz 顿挫；

**真机证据**：背景高频 **0.104 vs 视频 2.506**；10 帧帧差平滑无跳变；`resize_skips` **8→19**、拉伸 **0.035ms**、`blur_ms` **0.405→0.249**（<0.3ms）；接缝**几何自洽**（手柄右缘 953+16=**969** = 抽屉左缘）且两侧高频同量级（15.344 vs 18.318，Δ19%）、3× 目视过渡平滑。

## 四、本阶段方法论（6 条新增，已入 QA 基线）

1. **`QCursor.pos()` 判定类状态唤不醒**：`QTest.mouseMove` 只发 Qt 事件、不动系统光标 ⇒ 必须 **真实 `SetCursorPos` + `force_foreground` + `SendInput` + 拖拽线程化**（三条静默失效路径：逻辑坐标 / 未置前台 / 老 `mouse_event`）；
2. **`grab()` 首帧空白**：DWM 合成窗口里首帧绘制前 `grab()` 返回**全透明空 backing store** ⇒ 抓图前必须 `repaint()` + 等 **≥30ms**；透明子控件（lyrics/titlebar）不要单独 grab，从整窗裁；
3. **高光边会污染「磨砂层次」指标**：「逐行亮度 span」会被顶部高光边撑高 ⇒ 必须**剔除顶部行**并**同时看内容可见性**（文字/按钮是否真的可见）；
4. **标题栏空白区 `WM_NCHITTEST` 判 HTCAPTION** ⇒ 合成双击走 **NC 通道**、Qt 收不到 ⇒ 验证最大化用语义 `toggle_maximize()` 或真实光标双击；
5. **`self.xxx` 假设必须先 `hasattr` 自检**：本项目多次因「属性不存在却写在 try 里」→ 异常被吞 → 行为静默失效（`self.grid`、`_fader._t`、`drawer_state` 都栽过）；
6. **事件派发栈里不要开模态 `exec`**：`closeEvent`/`eventFilter` 里直接 `dialog.exec()` 会导致嵌套事件循环，点取消后主窗口被隐；正确做法 `ev.ignore()` + `singleShot` 推迟到下一轮事件循环。
