## 二、四张卡的真因与修法

### ① Task-129 滚动区白雾割裂带（P0 视觉）

**真因**：task-125 删除 `ScrollFeatherEffect` 后，为凑"24px 轻量渐变"指标，在 `settings_panel.py` 里新增了 `FeatherOverlay`（`QLinearGradient` 实色条，alpha 150），并在设置面板 7 个滚动区与播放列表抽屉 viewport 上安装 ⇒ 半透明玻璃上叠实色渐变条，必然出现色块割裂。

**修法**：全仓删除 `FeatherOverlay / _FeatherSync / install_feather / feather_stats / feather_ms / ScrollFeatherEffect` 及两处安装调用（settings_panel 与 playlist_drawer），滚动区 viewport 恢复 100% 纯净毛玻璃（只保留 viewport 原生矩形裁剪）。

**实测**（ui-chrome 探针 + QA 复验）：
- 设置面板 7 个滚动区 × 2 主题：隐藏内容后 viewport 顶部/底部 24px 带内像素 **15984/16320 → 0/0**，额外子控件 `FeatherOverlay×2 → 无`；
- 播放列表抽屉：`_feather` 属性消失、viewport 无额外子控件；
- 正控（注入复刻旧 24px 渐变）：仍能抓到 15984 px ⇒ 判据有效；
- 灰度 ramp：抽屉 top 69~102 → **4.0**、bottom → **2.7**；设置 top 10~30 → **0.2/0.33**；设置 bottom 9.6 但目视为**面板底部圆角+阴影**（zoom 图确认无白雾带），登记为误报例外。

### ② Task-130 悬停「词」/「1.0x」变空框（P0）

**真因**：`control_bar.py` 的 `_BareSpeedButton / _BareBadgeButton.paintEvent` 在函数内只 import 了 `QColor/QPainter(/QPen)`，**模块级没有 `QRectF`**。normal 态 `t<=0.01` 不进 hover 分支所以正常；鼠标一悬停 `t>0.01` 执行 `QRectF(self.rect())` 立即 `NameError`，`QPainter` 中途中止 ⇒ 前景（1.0x/词）不画 ⇒ 空框。

**修法**：模块级补 `QRectF`（+QColor/QPainter）；两个裸按钮重写为「背景层 try/except（`log.warning(..., exc_info=True)`）+ 前景层无条件绘制」，前景色每帧从当前调色板解析；`widgets.py` 的 `IconButton/TextIconButton.paintEvent` 同样拆成 `_paint_plate/_paint_glyph`（配方逐像素不变）。

**实测**（两主题 × 底栏 14 + 顶栏 6 按钮 × normal/hover/pressed/checked）：
- 「1.0x」hover 墨迹 **0 → 79（ratio 0.000 → 1.000）**；「词」**0 → 115（1.000）**；paint_error `NameError` → 无；
- violations **12 → 0（pass=True）**；换肤后前景色 `#141820 → #FFFFFF` 正确随调色板重解析；
- QA 独立复验：4 组（audio/video × dark/light）19 按钮全部 `ratio_final=1.0`、`bad=0`。

### ③ Task-131 缩略图歌名全丢 + 时长只有 3/14（P0）

**双真因**：
1. `playlist_drawer.GridDelegate._paint` 在标题绘制处使用**未定义变量 `_sel/_light`** ⇒ `NameError` 被 `paint()` 的 except 吞掉 ⇒ 标题分支永不执行，且 `painter.restore()` 被跳过；卡片几何也不符（136/86 vs 要求的 148/100）。
2. 时长只显示 1~3 首：`prober.py` 的兜底探针 `loadfile(path, options="vid=no,aid=no,audio=no")` ⇒ mpv 报 `NOTHING_TO_PLAY`、duration 永远读不到（实测基线 **0/7**、耗时 28.4s）；且缩略图位图生成时把时长"烤死"。

**修法**：
- 几何：卡片 160×148、缩略图 148×100 圆角 8、缩略图下 4px + 标题区 38px；`sizeHint 160×148` 与 `setGridSize 170×158` 同步；
- 标题：12.5px 设计值 → QFont 整数 13px Medium（实测 pointSizeF 9.375 与 13px 度量一致），2 行 ElideRight；`save/restore` 放进 `try/finally`；
- 字色按**抽屉实际合成底色亮度**取（`GLASS_FILL_DRAWER #FFFFFF8C` 叠舞台 ≈ RGB[152,152,152]）：正常 #181C24 / 选中 #0F62FE（对比度 16.62/5.92 : 1）；保留未来深底板的 #F0F4F8/#58A6FF 分支；
- 时长：渲染时实时读 `ROLE_DURATION`（缺失回落 `_duration_cache`），右下角动态画 `rgba(0,0,0,0.65)` 胶囊 + 纯白 mm:ss，无时长显示 `--:--`；
- `media/tags.py` 新增纯 Python `read_duration()`（MP3 ID3v2+Xing/Info/VBRI/CBR、FLAC STREAMINFO、MP4/M4A mvhd，0.08~1.3ms/文件，永不抛异常）；
- `prober.py` 头部秒读优先 + 兜底探针改 `audio=yes,video=yes,aid=auto,vid=auto,ao=null,vo=null,pause=yes`；`main_window` 两处 `set_items` 传全量 durations；`update_duration` 写回 item 并触发重绘。

**实测**（14 项：7 音视频 + 7 图片，两主题）：
- **14/14 歌名墨迹、14/14 时长胶囊、7/7 真 mm:ss（20/6/120/25.051/25/25/12s，误差≤0.01s）、7/7 图片 --:--**；
- 探针耗时 28.42s → **0.31s**；单卡绘制 0.28~0.31ms、整 viewport 3.3~3.5ms；
- 真机 MainWindow 端到端（offscreen+IPC）：14 卡、14/14 标题+胶囊（两主题）；超长歌名 2 行+省略号。

### ④ Task-132 音游模式全面升级（P0）

**真因**：
1. `RhythmStage` 高度 = 全高 712px ⇒ 判定线掉到控制栏/频谱背后被遮挡；
2. `rhythm_stage.quantize_events` 用 `e.get("hold")` 判断长按，但 `beatmap.py` 输出 `type="hold"/dur` ⇒ **HOLD 全退化成 TAP**；同时 `T_beat/2` 网格吸附把切分音砍掉；
3. 命中无反馈：音符触线即消失。

**修法**：
- 几何：`spec_top = h - CONTROL_BAR_H - SPEC_H - 16`；`rhythm_h = spec_top - 14`；判定线 = 舞台底内缩 18px。实测舞台 `[1240,0,180,542]`、判定线 524、频谱顶 556、**舞台→频谱 14px、判定线→频谱 32px**；回落路径 562/544；零硬编码，全部由 `_spec_y_for()/_rhythm_geometry()` 单一真源推导；
- 算法：废除 T/2 网格与 225ms 合并；跨轨最小 60ms、同轨最小 90ms；`beatmap` 用 50ms 音头窗 200~4000Hz **频谱质心** + 局部 ±3s **秩分位**映射 lane 0..3（低→高，旋律上下行）；质心无区分度时按时间均衡分轨；HOLD 由能量包络 220~2500ms ≥ 局部峰值 42% 生成，择优控 25%~40%；
- 视觉：TAP 34×10 圆角 5（深 rgba(120,220,255,.90) / 浅 rgba(15,98,254,.85) 渐变 + 1px 高亮描边）；HOLD 24px 半透明冰蓝流光面条带 + 中轴亮芯线，经过判定线时**尾巴实时截断**；4 枚圆角胶囊判定底座（高 10px）；命中 1.40x→1.0x 150ms 弹性回弹 + 110px/α0.50 光柱 + 34×10→52×26 扩散光环；HOLD 经过期间底座常亮放大 + 呼吸光柱 + 结束尾判光环。

**实测**（8 素材，全部 `chart_source=onsets`、`demo_events=0`）：

## 七、方法论沉淀

1. **"用户已接入副屏"是测试方式的硬约束，不是备注**：offscreen + grab + 隔离 APPDATA 能在零打扰下拿到像素级证据；把纪律写进 KB，后续所有项目复用。
2. **QA 必须能推翻"已 complete"**：本轮 beatmap 阈值回归就是 QA 在开发任务标记完成后抓出来的；任务状态不等于验收通过。
3. **静态漏导入体检值得常态化**：`check_qt_imports.py`（AST 作用域 + PySide6 公开名）一次扫出 3 处被 except 吞掉的 NameError，正是"悬停空框"同族缺陷。
4. **"源码修好 ≠ 交付物修好"再次验证**：所有结论最终要落到打包版 exe 的冒烟与 QA 复验。
