## 1. 关键技术结论（都可复跑）

1. **手柄随动不是「改成一条公式」就够了**：动画只改 drawer_slot 的固定宽度，布局要到下一轮事件循环才生效 —— 读几何前必须 layout().activate()，否则手柄整整慢一帧（逐帧 diff 恰好等于抽屉单帧位移 114→63→27）。
2. **封面阴影必须「内发散 + 跟随圆角」**：R1 最外 1px / R2 四角 2×2 必须 alpha≤8（=「无直角灰底」的量化定义）；同心圆角阴影的 alpha 只是「距封面边界距离」的函数，所以「角区 < 边中点」这类判据在几何上不成立（QA 原提法被 Lead 否掉并改判据）。
3. **频谱的三条硬几何**：42px 是**柱体总长**（控件仅 48px，上下各 21px）；中线 y_mid=h/2；_bars 现在直接存 px（旧探针若按 0..1 band 换算会得到 1848 这种离谱值）。
4. **停止语义的正确判据**：cached(idle-active) **恒 MISS**（不在观察列表）⇒ 必须直读；core-idle 在**暂停**时也是 yes ⇒ 用它会把暂停误判成停止、破坏「暂停定格」；而 MpvEngine.stop() 只停**事件线程**（实测 time-pos 仍在前进 2.886→5.706），**不是停止播放**。
5. **派生缓存必须随主题失效**：模糊背景缓存带 Vibrance 档位，切主题不重建 ⇒ 浅色下背景少 13~17% 饱和度（用户评估浅色模式的第一动作就是切主题）。修法：AudioView.on_theme_changed() ⇒ _bg_timer.start()（复用既有去抖）。
6. **真实能量接入**：af=@stats:lavfi=[astats=metadata=1:reset=1] + 直读 af-metadata 的 Overall.RMS_level（−29.07dB → 0.5167）；失败注入时安全回落模拟包络，音频链路不受影响。

## 4. 已知遗留与需用户主观定夺

1. **浅色正文对比度**：去掉白纱后背景变暗，标题/副标题对比度 **9.9:1 → 3.34:1**（低于 WCAG AA 4.5:1；Dev 独立算 3.27、QA 3.34）。这是「去漂白」的物理必然；可选项：浅色下改用更亮的字色 / 遮罩取上限 0.36 / 顶部加极淡渐变。**本轮按用户数值要求实现，未擅改**，请用户过目后定夺。
2. **频谱逐柱镜像**：分段镜像差 1.9%~7%（卡片口径 ≤15% 已过）；逐柱最大差 32% —— 来自「每柱独立振荡」的设计取舍，若要逐像素完全镜像需让振荡也镜像。
3. **mp3 码率显示 194kbps**（有效码率：文件大小÷时长）vs 容器声明 192kbps；两者都是真实值，QA 判通过。
4. **astats 滤镜常驻**：切到视频模式仍留在 af 链上（分析型滤镜，实测不影响播放/seek），按 Lead 裁决不开卡。
5. 启动时若 mpv 超过 ~3s 才给出 audio-params，规格胶囊会稍晚出现（最坏整枚隐藏，不会显示半成品）。
