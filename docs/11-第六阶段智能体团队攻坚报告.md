## 2. 本阶段挖出的四个真根因

1. **滚轮改不动歌词**：`AudioView` 设了 `WA_TransparentForMouseEvents` ⇒ 整个子树（含歌词面板）不在命中链，`widgetAt(面板中心)` 落到 Stage 覆盖层 ⇒ 滚轮永远到不了面板。改应用级事件过滤器按物理矩形拦截（不动该属性以免牵连窗口拖动）。
2. **全屏挡 Alt+Tab**：`toggle_fullscreen()` 调了 `win.set_topmost(True)`（走 `SetWindowPos(HWND_TOPMOST)`，**绕过 Qt flags**，所以 Qt 侧读不到）⇒ 全屏 `WS_EX_TOPMOST=True`。改标准 `setWindowState(|Qt.WindowFullScreen)`。
3. **幽灵热区复活**：`sync_hotspots()` 无条件 `z.show()`、`set_hotspots_enabled(True)` 无条件 `setVisible(True)` ⇒ 任何 resize / 开关抽屉都会把音频模式下刚隐藏的热区拉回可见。收敛到唯一决策点（模式 + 抽屉一起判）。
4. **歌词发糊**（上一阶段遗留确认）：离屏缓冲未乘 DPR ⇒ 「1× 渲染 + 最近邻 1.5× 放大」（mod3 强边缘余数指纹 imbalance 0.5231 → 0.0899）。
